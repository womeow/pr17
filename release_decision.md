# Итоговое решение для владельца процесса — DOC-17

## Решение

**ОСТАНОВИТЬ выпуск 1.5.0-rc1.** Кандидат не проходит обязательные критерии.

## Основание

| Критерий | Статус | Влияние |
|---|---|---|
| R_CREATE (T01) | passed | не блокирует |
| R_ACCESS (T02) | passed | не блокирует |
| R_IDEMPOTENCY (T03) | passed | не блокирует |
| R_RESTORE (T04) | **blocked** | блокирует выпуск: нет подтверждения RTO/RPO |
| R_PERFORMANCE (T05) | **not_run** | блокирует выпуск: критерий не измерен |
| Контроль целостности пакета | не подтверждён | блокирует: нет хеша |
| Руководство 1.4.2 | устарело, опасный совет | требует исправления до выпуска |

Любой подтверждённый дефект доступа, потери данных или дубля блокирует выпуск
независимо от общей доли успешных тестов. Пороги качества не снижаются.
