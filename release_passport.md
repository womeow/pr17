## Цель выпуска

Перевести учебный сервис заявок с 1.4.2 (S1) на 1.5.0 (S1/S2) с миграцией M015,
не нарушив критические сценарии (создание, доступ, идемпотентность, восстановление, производительность).

## Состав

- Приложение app-1.5.0-rc1 (Linux x64, Python 3.11/3.12, PostgreSQL 15/16).
- Миграция M015.
- Резервная копия B-1755 (database + attachments + config).
- Устаревшее руководство 1.4.2 — **требует исправления** (см. documentation_changes.md).

| Параметр | Назначение | Значение / место подстановки |
|---|---|---|

## Миграция и совместимость

- M015 — расширяющая, состояние отслеживается журналом миграций.
- Повтор миграции разрешён только после проверки фактического результата.
- Старое приложение 1.4.2 читает S2 до включения `category_required`;
  после включения и появления новых записей возврат требует согласованного преобразования данных.

## Ограничения и неподтверждённые поля

- **Контроль целостности пакета не подтверждён**: фактический файл app-1.5.0-rc1.zip
  недоступен, вычисленный хеш отсутствует. Имя файла хеш не заменяет.
- **Последнее испытание восстановления**: `not_available_in_packet` — данных нет.
- source_commit и synthetic-log — учебные маркеры, не внешние ссылки.
- Совместимость после включения category_required — не проверена.

## Статус готовности

**НЕ ГОТОВ к выпуску.** Причины: R_RESTORE заблокирован, R_PERFORMANCE не измерен,
контроль целостности пакета не подтверждён, руководство содержит опасный совет.
